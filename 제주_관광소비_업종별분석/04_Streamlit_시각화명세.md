# Streamlit 시각화·계산 명세

## 1. 공통 데이터 계약
자료 경로는 이 문서가 있는 폴더의 자료/ 아래다. 구현 시 상대경로를 기준으로 읽는다.
지역 키는 소비읍면동코드(7자리 문자열)와 구간이다. 표시명은 읍면동명이다. 상점행정동코드는 8자리 문자열이며 지도 경계와의 직접 일치는 보장하지 않는다. 구현 담당자가 경계파일을 준비하고 코드 체계·기준시점·43개 지역 매칭을 확인한다.
CSV는 utf-8-sig, 코드열은 문자열로 읽는다. pct는 0~100, pp는 %p다. 금액 단위를 확인하고 반올림은 표시할 때만 한다.

## 2. 필터와 재계산 정책
- 기본:3차년도(2025.08~2026.07),관광객은내국인+외국인합산고정.기본선정지역은43지역전체에서사전계산됨.
- 구간·유형·지역선택시기존행을필터링하고차트를갱신한다.지역을몇곳선택했다고분위수·제주비교값을재계산하지않는다.
- 임의기간·월범위선택을핵심판정필터에추가하지않는다.12개월을전제로한산식이기때문.월선택은강조·상세보기만가능.
- 관광객내국인/외국인별판정은이인계본에없음.합산결과를분리결과처럼표시하지않는다.

- 기본기준은Q75고정.민감도선택을제공할경우별도탐색화면으로분리하고기본유형덮어쓰기금지.

## 4. 누락·동률
월×업종 CSV는 관측행 7,662행이다. 완전한 7,740셀에 부족한 셀은 무조건 0으로 채우지 않고 원자료 행 없음으로 구분한다. 연간값은 관측행을 합산한 기존 결과다. 월 합계를 재집계하면 기존 129개 지역·구간 소비금액과 대조한다.
상점거래는공동최소순위.공동3위가있으면4개업종이표시될수있음.외도동숙박·예술스포츠공동3위유지.상위 월 동률은 재선택하지 않고 기존 CSV의 선택월을 사용한다.
